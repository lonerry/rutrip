## 1. Описание продукта

Rutrip — веб-приложение для ведения личной карты путешествий по России. Пользователь отмечает посещённые субъекты РФ на интерактивной карте, сохраняет любимые места точками, прикрепляет к ним фотографии и видео и пишет короткие истории о поездках. Друзья могут смотреть карты, истории и фото друг друга; посторонним личный контент недоступен.

Целевая аудитория — люди, которые путешествуют по России (самостоятельные туристы, студенты, семьи, блогеры) и хотят хранить воспоминания о поездках наглядно — в привязке к карте, а не в общей ленте фотографий.

Технологии: клиент — React + TypeScript (Vite, Tailwind CSS, Leaflet); сервер — Java 21, Spring Boot 3.5; база данных — PostgreSQL 16 с миграциями Flyway; развёртывание — Docker Compose на VPS.

## 3. Функциональность ПО

В приложении Rutrip реализуются следующие функциональные модули:

1. **Регистрация и вход:** регистрация по email, паролю и имени; вход по email и паролю; сессия на основе JWT-токена; выход из аккаунта.
2. **Восстановление пароля:** отправка 6-значного кода на почту; ввод кода и нового пароля; код действует 1 час и используется один раз.
3. **Интерактивная карта России:** границы всех 89 субъектов РФ; масштабирование и перемещение; посещённые регионы закрашиваются выбранным цветом; карточка региона с его фото, историями и точками.
4. **Отметки регионов:** отметить регион как посещённый (с датой и заметкой), снять отметку, выбрать цвет заливки для каждого региона; счётчик «посещено из 89».
5. **Поиск на карте:** поиск городов, природных объектов и достопримечательностей по названию и по координатам («56.01, 92.87»); провайдеры: Яндекс Геокодер → Mapbox → Photon/Nominatim (OpenStreetMap).
6. **Точки (любимые места):** создание точки нажатием на карту или из результата поиска; название и заметка; автоматическое определение региона; редактирование и удаление.
7. **Истории о поездках:** создание, просмотр, редактирование и удаление историй; привязка к региону и точке; прикрепление фото; поиск по историям.
8. **Фото и видео:** загрузка нескольких файлов сразу (JPEG, PNG, WebP, GIF, MP4, WebM, MOV); привязка к точке, истории или региону; полноэкранная галерея; потоковое воспроизведение видео.
9. **Профиль:** смена имени, загрузка и удаление аватара, цвет карты по умолчанию, статистика (регионы, истории, фото).
10. **Люди и друзья:** поиск пользователей по имени или email; отправка, принятие и отклонение заявок; удаление из друзей; просмотр карты друга.
11. **Уведомления:** колокольчик с числом непрочитанных; уведомления о новой заявке и о принятой заявке; «отметить всё прочитанным».
