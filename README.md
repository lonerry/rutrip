# Rutrip

Rutrip — личная карта путешествий по России. Здесь можно отмечать посещённые регионы, сохранять любимые места, добавлять фотографии и видео, а также писать небольшие истории о поездках.

Рабочая версия: [http://89.124.81.146](http://89.124.81.146)

## Возможности

- отметки посещённых регионов и выбор цвета для каждого из них;
- поиск городов, природных объектов и достопримечательностей (Яндекс Геокодер и Mapbox, OSM как запасной вариант);
- сохранение точек с описанием, фотографиями и видео;
- истории о поездках с привязкой к региону;
- профили, друзья и просмотр карт друг друга;
- загрузка аватара и восстановление пароля по почте.

## Технологии

Клиентская часть написана на React и TypeScript. Для карты используются Leaflet и тайлы Mapbox (если задан ключ), иначе Яндекс. Сервер работает на Spring Boot, данные хранятся в PostgreSQL, а схема базы обновляется через Flyway.

## Локальный запуск

Понадобятся Docker, Java 21 и Node.js.

Сначала запустите PostgreSQL и MailHog:

```bash
docker compose up -d
```

Затем запустите сервер:

```bash
cd backend
./mvnw spring-boot:run
```

Для подложки карты и быстрого поиска создайте файл `frontend/.env.local`. Если есть токен Mapbox, карта и поиск возьмут его в первую очередь:

```env
VITE_MAPBOX_TOKEN=pk.ваш_токен
VITE_YANDEX_MAPS_KEY=ваш_ключ
```

Тот же ключ Яндекса (тип «JavaScript API и HTTP Геокодер») сервер использует для поиска мест. Отдельный Geosearch для организаций — другой платный продукт, его ключ для тайлов не подходит. Чтобы бэкенд видел ключи локально, экспортируйте их перед запуском:

```bash
export YANDEX_MAPS_KEY=ваш_ключ
export MAPBOX_TOKEN=pk.ваш_токен
```

После этого запустите клиент:

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на [http://localhost:5173](http://localhost:5173), API будет доступно на порту `8080`, PostgreSQL — на порту `5433`. Тестовые письма можно посмотреть в MailHog: [http://localhost:8025](http://localhost:8025).

## Развёртывание

Для продакшена используется `docker-compose.prod.yml`. Перед запуском нужно задать как минимум:

```env
POSTGRES_PASSWORD=...
JWT_SECRET=...
VITE_YANDEX_MAPS_KEY=...
VITE_MAPBOX_TOKEN=...
YANDEX_MAPS_KEY=...   # можно тот же ключ, что и VITE_
MAPBOX_TOKEN=...      # можно тот же pk., что и VITE_
APP_PUBLIC_URL=...
```

Фотографии и видео хранятся в Docker-томе `uploads`, данные PostgreSQL — в томе `pgdata`. Команда `docker compose down -v` удалит оба тома вместе с данными.
