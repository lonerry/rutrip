# Rutrip

Личная карта поездок по России. Красишь субъекты, ставишь точки, пишешь, что там было, цепляешь фото и видео. Не лента и не чекин — скорее тетрадка, которую не стыдно открыть через год.

Сейчас крутится тут: [http://89.124.81.146](http://89.124.81.146)

Кликнул регион — справа выезжает карточка. Можно отметить визит, сменить цвет, залить снимки, набросать историю. На большом зуме точка ставится сразу с клика, места ищутся поиском: написал «телецкое озеро» — карта туда уехала. Есть друзья и чужие карты, если пустили.

Спереди React и Leaflet, тайлы Яндекса. Сзади Spring Boot и Postgres.

## У себя

Нужны Docker, Java 21 и Node.

```bash
docker compose up -d
cd backend && ./mvnw spring-boot:run
```

В `frontend/.env.local` ключ карт, без него подтянется запасной слой, но Яндекс выглядит лучше:

```
VITE_YANDEX_MAPS_KEY=...
```

```bash
cd frontend && npm i && npm run dev
```

Фронт на [localhost:5173](http://localhost:5173), апи на 8080. Postgres проброшен на **5433**, не 5432 — так меньше конфликтов с локальным постомгресом. Письма восстановления пароля без SMTP падают в логи, либо в MailHog на [localhost:8025](http://localhost:8025).

Прод собирается через `docker-compose.prod.yml`. Там уже не обойтись без нормальных `JWT_SECRET` и `POSTGRES_PASSWORD`. Фото и видео пишутся в том `uploads` (`/data/uploads` в контейнере), база — в `pgdata`. `down -v` это всё сотрёт, так что не надо.

Ключ Яндекса на проде передаётся как build-arg `VITE_YANDEX_MAPS_KEY`, он запекается в фронт при сборке образа.
